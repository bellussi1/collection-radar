## Better World Books

Não serve para este conjunto:

- 9780007562251 (Assassin's Apprentice): **temporarily unavailable**.
- 9780007585892 (Fool's Errand): só "other available editions", mass market a
  partir de US$ 27,23; não é o paperback UK de 198 mm.
- 9780008154394 (Dragon Keeper): sem preço direto; a série aparece em edições US.
- A busca por "robin hobb" devolve majoritariamente edições Del Rey/Bantam
  americanas, não as HarperVoyager UK.

Para o conjunto uniforme, a Better World Books não é um bom orçamento. Ela pode
servir para edições americanas de outros autores (Sanderson/Tor, Ruocchio/DAW,
Dinniman/Ace), mas não para este caso.

## O que isso significa para a decisão

- Se o critério é **certeza de edição**: AbeBooks, comprando por ISBN. Custa
  ~R$ 300 a mais que os sets da Amazon BR, mas elimina o risco de vir Del Rey,
  mass market ou uma mistura.
- Se o critério é **preço**: os 5 sets da Amazon BR (R$ 1.669,56) continuam mais
  baratos, mas você precisa confirmar com o vendedor que são os volumes
  HarperVoyager de 198 mm. O set de Fitz and the Fool é o mais suspeito
  (editora listada como "Generic").
- Se o critério é **misto**: compre na Amazon BR só os sets cujo anúncio diga
  HarperVoyager e tenha dimensões compatíveis; complete o resto pela AbeBooks.
  O Tawny Man e o Rain Wild são os melhores candidatos a set; o Fitz and the
  Fool eu compraria por ISBN.
